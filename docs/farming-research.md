# 농사 탭 사전 조사 — 공략 검증과 소스 기준 데이터 (#117)

> 2026-09-17 조사. 피드백(2026-08-29) "농사 탭은 추가될 가능성이 있나요? (추천 비료/작물 조합)" 대응을 위한 사전 작업이다.
> 구현 문서가 아니라 **조사·검증 기록**이다. 구현을 시작할 때 이 문서의 "7. 기능 설계 시사점"부터 읽을 것.

## 0. 결론 요약

1. **농사 공략의 핵심은 전부 게임 소스에 수치로 있다.** 작물별 제철·양분·물, 양분 순환 규칙, 스트레스 7항목과 거대 작물 조건, 비료 양분값, 돌보기 도구 범위, 일반 씨앗 확률까지 소스에서 나온다. 블로그에 의존할 필요가 없다.
2. **"추천 조합"은 계산 결과다.** 작물은 자기 양분을 먹고 먹은 만큼을 안 먹는 양분에 나눠 되돌리므로, 조합은 "타일 안 순변화 합이 (0,0,0)"이 되는 비율 문제다. `scripts/farm-combos-prototype.py`가 소스만으로 계산한 기본 조합(봄 12·여름 4·가을 10·겨울 2)은 나무위키의 접힌 목록 28줄과 **줄 단위로 전부 일치**하고, Steam 한국어 가이드(lota)가 코드로 뽑은 93개 조합도 **전부 포함**한다.
3. **공략에는 오류가 꽤 있다.** 읽은 10개 출처 중 오류가 없는 곳은 없었다(5장 로그 참고). 서로 다른 칸에서 틀리기 때문에 공략끼리 대조해서는 못 잡고, 소스로만 판정된다. 패치로 수치가 바뀌어도 `sync-game-data.sh` 파이프라인에 올리면 자동 추종된다.
4. **계산으로 안 되는 부분**은 실전 감각이다. 괭이질 좌표 경계(정확히 4.0 거리), 양분 소비 순서로 인한 일시적 고갈의 실제 빈도, 물 주기 체감. 6장에 정리했다.

## 2. 소스 기준 메커니즘

모든 수치는 `~/dst-game-snapshot/scripts/` (buildid는 `src/data/game-version.ts` 참고) 기준이다. 1타일 = 4단위.

### 2.1 성장 단계와 검사 시점
- 5단계: 씨앗 → 싹 → 작음 → 중간 → 자람. **단계가 넘어갈 때마다(4번)** 7개 스트레스 항목을 검사하고, 걸린 항목마다 1점. 최대 28점 (`components/farmplantstress.lua`).
- 성장 시간 (`prefabs/farm_plant_defs.lua` `MakeGrowTimes`): 발아 12~16 seg(0.75~1일), 이후 전체 4~7일을 싹 50%·작음 30%·중간 20%로 나눔. 작물 14종 모두 같은 값.
  - 직전 검사에서 받은 스트레스가 많을수록 최소→최대 쪽으로 늘어난다 (`CalcGrowTime`, 최대 1.75배). **제철이면 전부 ×0.5.**
  - 제철·무스트레스 기준 총 약 2.4~2.5일, 제철 아님·고스트레스 약 8일. 성장은 햇빛(낮·저녁, 동굴 채광, 난쟁이별 등)이 있을 때만 진행.
- 다 자란 뒤: 일반 작물 4일, 거대 작물 6일 안에 수확하지 않으면 썩는다(웜우드가 심으면 ×1.5 `FARM_PLANT_LONG_LIFE_MULT`). 일반 작물은 썩은 뒤 4~5일 후 다시 자라지만 그때는 거대 작물이 될 수 없다.

### 2.2 스트레스 7항목 (`prefabs/farm_plants.lua`)

| 항목 | 규칙 | 소스 상수 |
|---|---|---|
| 양분 | 타일에 필요한 양분이 모자라면 +1. 모자란 만큼 **되돌리는 양도 줄어든다** | `CycleNutrientsAtPoint` |
| 수분 | 직전 단계 이후 젖은 땅(수분>0) 위에 있던 시간이 10% 미만이면 +1 | `FARM_PLANT_DROUGHT_TOLERANCE = 0.10` |
| 분위기 파괴자 | 반경 6(1.5타일) 안에 썩은 작물·잡초·텃밭 쓰레기·**썩은** 거대 작물이 하나라도 있으면 +1. 멀쩡한 거대 작물은 해당 없음 | `FARM_PLANT_KILLJOY_RADIUS = 6`, tolerance 0, 태그 `farm_plant_killjoy` |
| 제철 | 현재 계절이 제철이 아니면 +1 | `good_seasons` |
| 가족 | 반경 4(1타일) 안에 **같은 작물**이 자신 포함 4포기 미만이면 +1. **타일 경계와 무관한 반경 판정** | `FARM_PLANT_SAME_FAMILY_MIN = 4`, `_RADIUS = 4` |
| 과밀 | **같은 타일**에 작물·잡초가 10포기를 넘으면(11포기부터) +1 | `FARM_PANT_OVERCROWDING_MAX_PLANTS = 10` (소스 오타 그대로) |
| 행복(돌보기) | 직전 단계 이후 한 번도 돌봄을 못 받았으면 +1. 불이 붙거나 초파리에게 공격당하면 돌봄이 취소된다 | `farmplanttendable` |

핵심은 **양분·과밀은 타일 단위, 가족·분위기 파괴자는 반경 단위**라는 점이다. 같은 작물을 타일 경계 너머에 이어 심으면 가족은 채워지지만 양분은 섞이지 않는다 (나무위키의 "좋은 예/나쁜 예" 그림이 이것).

### 2.3 스트레스 합계 → 수확물 (`SetupLoot`, `farmplantstress:CalcFinalStressState`)

| 합계 | 등급 | 수확물 |
|---|---|---|
| 0~1 | NONE | **거대 작물** 1개 (망치로 부수면 작물 2 + 씨앗 2 + 75% 확률로 작물 1, 아니면 씨앗 1 → 기대값 작물 2.75 · 씨앗 2.25) |
| 2~6 | LOW | 작물 1 + 씨앗 2 |
| 7~11 | MODERATE | 작물 1 + 씨앗 1 |
| 12~ | HIGH | 작물 1 |

- 제철에 심고 방치하면 양분 4 + 수분 4 + 행복 4 = 12점이라 씨앗을 못 돌려받는다. 한 항목만 챙겨도 11점 이하가 되어 씨앗 1개가 나온다.
- 썩은 거대 작물: 부패물 3 + 씨앗 1 + **초파리 2마리**. 썩은 일반 작물·잡초를 수확하면 5% 확률로 초파리.
- 거대 작물은 아이템 상태로 유통기한이 작물의 4배(`OVERSIZED_PERISHTIME_MULT`)이고 바닥에 두므로 ÷1.5(`PERISH_GROUND_MULT`). 예: 용과 6일 → 16일. 부수면 신선한 작물이 나온다 (나무위키의 "겨울까지 용과 보관" 팁의 근거).
- 초파리 대왕: 반경 4 안에 다 자랐거나 썩은 작물이 15포기 이상이면 등장 조건 (`LORDFRUITFLY_SPAWNERCOUNT/RADIUS`).

### 2.4 양분 (`components/farming_manager.lua`, `tuning.lua`)
- 3종: 성장 촉진제 / 퇴비 / 거름 (소스 인덱스 1/2/3, ko.po `UI.PLANTREGISTRY.NUTRIENTS.NUTRIENT_1..3`). 타일마다 0~100, **새 밭은 각각 20~40** (`STARTING_NUTRIENTS_MIN/MAX`).
- 소비량은 2 / 4 / 8 세 등급 (`FARM_PLANT_CONSUME_NUTRIENT_LOW/MED/HIGH`). 작물은 소비하지 않는 양분에 **소비 총량을 균등 분배**해 되돌린다. 현재 작물 14종은 전부 나누어떨어져서 소스의 "잉여 랜덤 분배" 경로는 발동하지 않는다.
- 잡초 4종은 세 양분을 2씩 소비하고 아무것도 되돌리지 않는다. 텃밭 타일이 아닌 곳(웜우드 직파)은 양분 검사가 항상 실패한다.

### 2.5 수분
- 타일마다 0~100. 물뿌리개·물부리개·물풍선 1회 +25 (물뿌리개 40회, 물부리개 160회). **얼음 1개가 녹으면 +25** (`ICE_MELT_GROUND_MOISTURE_AMOUNT`). 비는 최대 +1.5/초.
- 건조: 0° 이하 0, 70° 이상 0.05/초 (`SOIL_MIN/MAX_TEMP_DRY_RATE`). 작물은 낮밤 없이 마신다: 저 0.0075 / 중 0.02 / 고 0.035 (초당, 포기당).
- 검산: 가장 물을 많이 먹는 흔한 구성(토마토란 6 + 용과 3)은 타일당 0.27/초라 1회 급수(25)로 약 93초 젖어 있다. 제철 싹 단계는 햇빛 기준 1일(480초)이고 밤을 포함한 실제 시간은 더 길어 10%가 대략 50~60초이므로 **"단계마다 한 번 급수"로 충분**하다는 위키·Klei 가이드의 설명과 맞는다. 한여름 고온(+0.05/초)에서는 약 78초로 여유가 줄어 2회가 안전하다.

### 2.8 잡초 (`prefabs/weed_defs.lua`)
- 일반 씨앗의 20%가 잡초(`FARM_PLANT_RANDOMSEED_WEED_CHANCE`). 가중치: 건망초 5, 불쐐기·뒤엎시라·가시올무메꽃 각 0.5 → 15.4% / 1.5% / 1.5% / 1.5%.
- 물 소비: 건망초 저(0.0075), 나머지 중(0.02). 성장 2~3일. 건망초는 추대 단계에서 3~5일마다 퍼지고, 나머지는 다 자란 뒤 6~8일마다 퍼진다.
- 뒤엎시라: 0.75~1일마다 텃밭 쓰레기 생성, 최대 5개. 불쐐기 접촉 피해 3. 가시올무메꽃 올무 피해 10.

## 3. 계산된 데이터 표 (`scripts/farm-combos-prototype.py` 출력 그대로)

양분 열 순서는 [성장 촉진제, 퇴비, 거름]. 팬덤 블로그는 [퇴비, 촉진제, 거름] 순서로 적어 숫자 배열이 달라 보이지만 내용은 같다.

### 3.1 작물 표 (성장 단계 1회당 타일 양분 순변화 / 물 소비)

| 작물 | 봄 | 여름 | 가을 | 겨울 | 성장 촉진제 | 퇴비 | 거름 | 물(/초) |
|---|---|---|---|---|---|---|---|---|

## 4. 조합 검증

### 4.1 계산 원리
- 작물 14종은 **양분 프로필 8종**으로 묶인다(3.1 표에서 순변화가 같은 작물끼리). 같은 프로필 작물은 양분 면에서 완전히 대체 가능하다: 당근=호박, 옥수수=아스파라거스, 감자=가지, 양파=석류, 마늘=두리안, 용과=고추. 토마토란과 수박은 단독 프로필이다. 디시 표에서 한 칸에 세로로 쌓인 작물, 나무위키·lota 목록의 `/`가 이것이다.
- 단, **가족 판정은 작물 단위**다. 감자 2 + 가지 2는 양분상 감자 4와 같지만 가족 4포기는 못 채운다 (Steam EN1 가이드도 "OR은 섞지 말라"고 명시).
- 기본 조합 = 프로필 3칸 이하의 기약 비율 중 더 작은 균형 조합의 합으로 쪼개지지 않는 것. 3.3 표가 전부다. 프로필 4칸·합 9 이하까지 넓히면 봄 84 / 여름 16 / 가을 44 / 겨울 3가지가 나오지만 대부분 기본 조합의 합성이다.

### 4.3 배치에서 배운 것
- **타일당 9포기(3×3) 또는 10포기**가 표준. 10포기는 3-2-3-2 엇갈림 배치이고 Snapping Tills 모드의 hexagonal 옵션이 사실상 필요하다.
- 1:1 조합(4+4, 5+5)만 타일 하나로 가족까지 해결된다. 3×3에 4+4를 심으면 가운데가 비는데, 거기에 소리고둥(반경 0.5타일)을 두면 그 타일만 정확히 돌봐진다.
- 2:1·1:1:1·2:2:1 조합은 **같은 구성의 타일을 붙여서** 같은 작물 줄이 경계를 넘어 이어지게 한다. 나무위키에 따르면 1:1:1은 3열 + 옆 타일 1열(같은 작물 4포기 일렬)만 있어도 거대 작물이 나온다.
- 소수 작물(2포기짜리)은 타일 경계 쪽에 모아 옆 타일의 2포기와 합쳐 4포기가 되게 배치한다 (나무위키 1:2:1, 2:1:2 그림 / 팬덤 블로그 "소수 작물은 가운데에").
- Klei 가이드: 열 배치에서는 농장 네 모서리의 4포기가 가족을 못 채운다. 농장이 커져도 실패는 4포기로 고정.

### 4.4 양분 소비 순서 함정 (Klei 가이드) — 계산으로 정량화 가능
- 작물은 **먼저 자기 양분을 받아야** 되돌린다. 어떤 작물이 단계를 넘길 때 타일에 양분이 모자라면 스트레스 1점 + 되돌리는 양 감소 → 상대 작물도 모자라는 연쇄가 생길 수 있다.
- 최악의 경우는 한 프로필의 작물이 전부 먼저 넘어가는 것이므로, **타일에 필요한 완충량 = 그 타일의 양분별 소비 합계**다. 3.3 표의 "최악 순서 수요" 열이 이것이고 새 밭 최소값 20과 비교했다.
  - 4+4, 5+5, 중급 1:1:1(3+3+3), 2:2:1 계열은 수요 ≤ 20이라 새 밭에서도 안전.
  - **고급 작물 3포기가 들어가는 구성(용과·고추·양파·석류·마늘·두리안 ×3)은 수요 24**라 새 밭(20~40)에서 운이 나쁘면 첫 단계에 모자랄 수 있다. 해당 비료를 한 번 주면 해결된다. 영문 위키와 디시 글이 "처음엔 비료를 조금 넣어 두라"고 한 이유.
  - Klei 가이드의 "72 이상 채워 두면 영구히 안전"은 고급 작물 9포기(9×8) 기준의 상한이다.
- 스트레스 1점까지는 거대 작물이 되므로 한 번의 부족은 치명적이지 않다.

## 6. 미해결 — 사용자 확인이 필요한 것
1. **정확히 4.0 거리의 가족 판정.** 3×3 격자(간격 4/3)에서 같은 작물 4포기를 일렬로 두면 양 끝 거리가 정확히 4.0이다. 나무위키는 된다고 하고 Klei 가이드는 열 배치 모서리가 실패한다고 한다. 괭이질 좌표(모드 스냅 vs 수동)에 따라 갈릴 수 있어 인게임 확인이 필요하다.
2. **양분 순서 함정의 실제 빈도.** 4.4는 최악의 경우 계산이다. 같은 날 심은 작물의 단계 전환 순서가 실제로 얼마나 쏠리는지는 모른다.
3. **물·돌보기의 체감.** "단계당 1회"가 계산상 맞지만 실전에서 편한 주기는 플레이 경험이 필요하다.
4. lota 목록의 추림 기준, "2,161가지"의 정의.
5. 미조사: 웜우드 직파·개화, 위커바텀 원예학 책(스트레스는 반영되나 거대 작물 불가라는 나무위키 설명), WX-78 회로, 초파리 대왕 운영, 퇴비통 효율, 일반 씨앗 → 작물 씨앗 불리기 초반 전략.

## 7. 기능 설계 시사점
1. **파이프라인**: `extract-raw-foods.py`와 같은 방식으로 `farm_plant_defs.lua` · `weed_defs.lua` · `veggies.lua`(seed_weight) · `tuning.lua`(FARM_*, *_NUTRIENTS, 돌보기 범위)를 읽어 `src/data/farming.ts`(자동 생성, 수동 편집 금지)를 만든다. `sync-game-data.sh`에 연결하면 패치 자동 추종. 프로토타입의 assert(양분이 나누어떨어짐)는 파이프라인에도 넣어 규칙이 바뀌면 빌드가 알려주게 한다.
2. **조합은 데이터로 저장하지 말고 계산**한다(빌드 시 생성 또는 런타임). 출처 표기 부담도 없다.
3. **추림과 표시**: 디시 표 형식이 정답에 가깝다 — 계절 → 조합 줄, 칸 = 양분 역할, 칸 안에 대체 작물(`ItemSlot`), 숫자 = 타일당 포기. 기본 조합 28개를 먼저, 나머지는 접는다. 줄마다 "타일 1개로 충분 / 같은 구성 타일을 붙일 것", "새 밭 안전 / 비료 1회 권장(어떤 비료)"를 붙인다.
4. **참고표**: 작물(제철·양분·물·씨앗 확률), 비료(양분값·횟수), 돌보기 도구(범위), 스트레스 7항목과 수확물. 여기까지가 피드백 요청("추천 비료/작물 조합")의 직접 답이다.
5. **배치도**(2단계): 타일 경계 음영 + 작물 아이콘 격자. 좌표가 있으면 가족 반경 검사를 직접 돌려 "이 포기는 가족 미충족"을 표시할 수 있다.
6. **용어는 ko.po**: 성장 촉진제/퇴비/거름, 토마토란, 텃밭 쟁기계, 괭이, 물뿌리개/물부리개, 원예사의 모자, 씨앗 줘-머니, 퇴비통, 성장 촉진제 원액/초 성장 촉진제, 거름통, 퇴비쌈, 나무 잼, 왱비료, 영양 블록, 농작물 등급 측정기, 텃밭 쓰레기, 건망초/뒤엎시라/불쐐기/가시올무메꽃. 스트레스 항목의 한국어 이름은 ko.po에 UI 문자열이 없어서(도감 UI에는 양분 소비/배출만 있음) 나무위키 표기(영양분·수분·분위기 파괴자·제철·가족·과밀·행복)를 쓸지 정해야 한다.
7. 이미지: 작물·씨앗·거대 작물·비료 이미지는 이미 있다. 양파 작물 이미지 1장만 없다.
